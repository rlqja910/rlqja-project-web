# 안전 작업 절대 규칙 (Safe Operations Rule)

- **파괴적인 Git 명령어 절대 사용 금지:** `git clean -fdx` 나 작업 디렉토리 내의 추적되지 않는(untracked) 파일을 일괄 삭제하는 그 어떤 명령어도 절대 실행하지 마라. 이 명령어들은 휴지통을 거치지 않고 완전히 영구 삭제해 버리므로, SSH 접속 키(`.pem`), 환경 변수 파일(`.env`) 등 치명적으로 중요한 파일들을 날려먹는 원인이 된다.
- **키 파일(Key Files) 절대 보존:** `LightsailDefaultKey-ap-northeast-2.pem` 파일이나 기타 `.pem`, `.key` 파일들은 AWS 배포를 위해 필수적인 파일이다. 어떠한 경우에도 이름을 바꾸거나, 옮기거나, 삭제해서는 안 된다.
- 만약 레포지토리를 정리해야 할 일이 있다면, 오직 특정 파일만 명시해서 지우거나 추적 중인(tracked) 파일만 안전하게 복구(checkout/reset)해라. 절대로 untracked 파일을 맹목적으로 날려버리지 마라.
